# Background

**Question:** *How well can a resazurin metabolic assay predict the survival phenotype of an oyster family, and do the same metabolic features predict performance under high-salinity vs low-salinity conditions?*

Two independent datasets describe the same 48 families:

1. **Survival phenotypes** — `data/ploidy/field/ploidy_field_performance.xlsx` records each
   ploidy's observed performance. 
   
- Definitions: 

    - SH is shell height (longest measure)
    - SL is shell length (across the ‘fan’)
    - SW is shell width (typically the shortest dimension)
    - Fan is SL/SH
    - Cup is SW/SH
    - WWW is whole wet weight
    - DSW is dry shell weight
    - DTW is dry tissue weight
    - CI is condition index and we use 100 x DTW/(WWW-DSW)

2. **Metabolic curve features** — `output/ploidy/resazurin-curves/curve_features.csv`
   contains ~25 curve shape/capacity/rate traits per individual extracted from
   resazurin assay timecourses (AUC, Vmax, metabolic scope, depression index,
   resilience ratio, trajectory class, etc.).

## Expected inputs

| Path | Description |
|------|-------------|
| `output/ploidy/resazurin-curves/curve_features.csv` | Per-individual curve traits |
| `data/ploidy/field/ploidy/field_performance.xlsx` | Ploidy performance |

## Expected outputs

All written to `output/ploidy/resazurin-prediction/`.

| File | Description |
|------|-------------|
| `family_feature_matrix.csv` | Ploidy-mean resazurin features by parentage group |
| `feature_phenotype_correlations.csv` | Spearman/Pearson correlations for all features |
| `top_predictors.csv` | Best-correlated features for each survival condition |
| `lofo_cv_performance.csv` | LOFO-CV performance for candidate predictors |
| `resazurin_index_predictions.csv` | Per-family observed vs predicted for composite index |
| `figures/` | Correlation ranking, comparison scatter, best-predictor, index, heatmap |
